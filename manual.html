操作手冊

「SCAMPER 創新思考法產生器」把經典的 SCAMPER 創新思考法做成互動網頁：輸入一個現有產品、服務或問題，依 Substitute（替代）／Combine（合併）／Adapt（調整）／Modify（修改）／Put to Another Use（其他用途）／Eliminate（消除）／Reverse（重組）七個角度逐一發想創新點子，最後綜合評估選出最具潛力的前三個方案。所有欄位都可以直接點擊手動編輯，AI 只是加速發想的選用功能。

什麼是 SCAMPER

SCAMPER 是七個創新提問角度的字首縮寫，逐一用不同角度「逼問」既有主題，避免思考卡在單一慣性方向：

  • S · Substitute 替代：有什麼元素、材料、角色、流程可以被替換掉？
  • C · Combine 合併：可以把哪些功能、產品、團隊、步驟結合在一起？
  • A · Adapt 調整：可以向哪個其他領域、案例、產業借鏡調整？
  • M · Modify 修改（放大／縮小）：把某個特性放大、縮小、加強或弱化會怎樣？
  • P · Put to Another Use 其他用途：現有資源還能用在什麼意想不到的地方？
  • E · Eliminate 消除：拿掉哪個步驟、功能、限制之後反而更好？
  • R · Reverse 重組／反轉：把順序、角色、因果邏輯顛倒會產生什麼可能？
SCAMPER 的價值不在七個角度都要用力想出驚天動地的點子，而在「強迫換位置提問」——有些角度對某個主題特別有效，有些角度想不出來也沒關係，重點是七個角度都認真問過一輪。

操作步驟

  1. 在最上方「主題」欄位輸入想改造創新的產品、服務或問題，或直接點選下方 5 組內建範例快速開始（其中「巷口手沖咖啡吧」附完整手打示範內容）
  2. 手動點擊七構面卡片裡的欄位直接輸入 2-3 個點子，或展開「API 連線設定」填入你自己的 LLM API 金鑰後按「🧠 AI 一鍵展開全部七構面」，一次生成全部七構面的點子
  3. 對某一個構面的點子不滿意，可以只按該張卡片旁的「🧠 AI 重新生成此構面」單獨重來，不會動到其他構面；也可以按「＋新增點子」手動加一列
  4. 覺得特別有潛力的點子，按旁邊的「⭐選入前三」帶到下方「綜合評估」區塊，自行填寫理由與落地建議；也可以按「🧠 AI 綜合評估：選出前三方案」讓 AI 從你已填的點子中挑選並附上理由與建議
  5. 填寫「整體總評」總結這次拆解後最值得優先推動的方向
  6. 完成後可「複製為文字」、「下載 .txt」，或按「🖨 列印 / 存 PDF」輸出成報告
所有內容自動存在這台瀏覽器的 localStorage，重新整理頁面不會遺失；不同電腦或清除瀏覽器資料就會不見，請自行下載 .txt 備份重要內容。「選入前三」是複製文字進去，之後刪除原始點子不會影響已選入的評估內容。

AI 功能（選用，需自備 API 金鑰）

展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID。

  • 「🧠 AI 一鍵展開全部七構面」會依目前主題一次生成七構面共 14-21 個點子，直接覆蓋目前已填寫的內容（會先跳出確認）
  • 每張構面卡片旁的「🧠 AI 重新生成此構面」只會重新生成該構面的點子，適合單一構面不滿意時局部重來
  • 「🧠 AI 綜合評估：選出前三方案」會讀取你目前七構面裡已填的所有點子，選出最具商業價值或突破性的 3 個並附理由與落地建議，直接覆蓋整個綜合評估區塊
  • 沒有填 API 金鑰完全不影響使用——所有欄位本來就可以直接手動編輯
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

隱私說明

  • 你填寫的主題、七構面點子、綜合評估內容都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，請自行用「下載 .txt」備份重要內容
  • API 金鑰同樣只存在瀏覽器的 localStorage；按下「AI 一鍵展開全部」「AI 重新生成此構面」或「AI 綜合評估」時，你的主題與已填內容會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
